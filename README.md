## Python Programming Course (10 Weeks)

**Instructor:** Matin Ghasemi<br>
**Institution:** Iran University of Science and Technology<br>
**Duration**: 10 Weeks<br>
**Format**: Lectures + Hands-on Practice + Assignments

### Course Overview
This course provides a structured and practical introduction to Python programming, designed for undergraduate and early graduate students at Iran University of Science and Technology. The focus is on building strong programming fundamentals, problem-solving skills, and the ability to write clean, readable, and efficient Python code.

By the end of the course, students will be able to independently develop small to medium-scale Python programs and will be prepared to use Python in academic, research, and applied settings.
